## 1. 定义与边界

身体层面的健康：体检异常、慢性小病、急病、意外受伤、职业病、工伤、运动、作息。心理健康单独见 [mind.md](mind.md)。

**状态**：`健康`（0–100），以及持续状态模块 `chronic`（慢性病）、`injury`（伤病恢复期）。

## 2. 规模与画像

本领域缺少直接对应 22–35 岁人群的统计，暂以【设计】为主：

- 【待核实】年轻人体检异常检出率（甲状腺结节、脂肪肝、高尿酸等）。
- 【待核实】职业病新发病例和工伤认定数量。
- 【待核实】交通事故中骑手、网约车司机的比例。

**设计原则**：22–35 岁死亡概率很低，身体事件以"小病、体检异常、意外受伤、累垮"为主；重病极少，但要有。

## 3. 触发方式

| 事件 | 【设计】触发 |
| --- | --- |
| 小病 | 每年 1–2 次，健康 < 50 时 ×2 |
| 体检异常 | 有单位体检时每年一次检查，健康 < 60 时出现异常 |
| 意外 | 每年 2%，骑手、工厂 ×3 |
| 重病 | 13 年内约 1%【待核实：按年龄段的重病发病率】 |
| 职业病 | 工厂、工地 4 年以上 |

## 4. 22–35 岁的典型节奏

| 年龄 | 典型事件 |
| --- | --- |
| 22–25 | 熬夜、外卖、感冒发烧、第一次体检 |
| 26–30 | 颈椎、腰椎、体检结节、开始健身 |
| 30–35 | 脂肪肝、高血压前期、代谢下降、"养生" |

## 5. 对状态的影响

- 健康每年基线 −1；加班重 −3；运动 +3；睡眠好 +2。
- 健康 < 40：工作效率下降，"工作冲刺"效果减半。
- 健康 < 20：触发"被迫休养"，暂停当前路径 1–6 个月。
- 医疗费按自付比例计算【待核实：职工医保与灵活就业医保的自付比例】。
