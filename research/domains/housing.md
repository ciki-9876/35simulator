# 领域档案：住房

| 项 | 内容 |
| --- | --- |
| 领域 id | `housing` |
| 事件量目标 | 70 条（本档案提供 23 个种子） |
| 状态 | v1，2026-10-29 |

## 1. 定义与边界

住在哪里、怎么住：宿舍、合租、整租、住父母家、单位宿舍、买房、房贷、换房、断供。

**持续状态**：`housing_status`（宿舍 / 合租 / 整租 / 父母家 / 自有）；模块 `mortgage`（房贷）。

## 2. 规模与画像

- 【数据】5 年期以上 LPR 自 2025 年 5 月下调后一直为 3.5%（2026 年 6 月仍未变）；首套房普遍执行"LPR 减点"，多地实际利率约 3.0%，部分城市叠加财政贴息低至 2.95%。
- 【报道】按 100 万元、30 年等额本息、利率 3.0% 计算，月供约 4,216 元。
- 【数据】限购持续放松：2026-08-08 起北京非京籍家庭在全市购房的社保或个税年限统一为连续缴纳满 1 年；上海外环外、深圳也是 1 年（深圳 2025-09-06 起，多数区不限套数）。
- 【待核实】一线、新一线城市的房价收入比和租金走势。

**对游戏的影响**：一线城市的人多数在 35 岁前一直租房；二线以下城市和有家里支援的人更早买房。房贷是"被裁"时最大的压力来源。

## 3. 触发方式

| 事件 | 【设计】触发 |
| --- | --- |
| 找房 | 毕业、换工作、换城市时 |
| 房东事件 | 合租或整租时每年 30% |
| 买房抉择 | 存款 + 家庭支援 ≥ 首付（按城市档），或结婚时 |
| 房贷压力 | 有房贷，收入下降或失业时 |

## 4. 22–35 岁的典型节奏

| 年龄 | 典型事件 |
| --- | --- |
| 22–25 | 合租、隔断、通勤、和室友合住 |
| 26–30 | 整租、攒首付、看房、婚房 |
| 30–35 | 房贷、换房、房价波动、断供风险 |

## 5. 对状态的影响

- 房租【设计】：一线城市整租占收入 30–50%，合租 20–30%；二线以下 15–25%。
- 通勤：【设计】一线城市单程 1 小时以上时心情每年 −3、健康 −2。
- 房贷：月供 > 收入 50% 时心情每年 −5；失业时触发"断供"连锁。
- 有房：心情 +5（安全感），但流动性下降，换城市更难。

## 6. 与路径和模块的关系

| 路径或模块 | 关系 |
| --- | --- |
| 大厂 | 高收入买房 + 被裁断供，见 8.1 |
| 体制内 | 公积金高，买房容易 |
| 自由职业 | 收入证明难，贷款难 |
| 恋爱与婚育 | 婚房 |
| 父母与家庭 | 首付支援 |
| 城市与迁移 | 落户、限购、回老家买房 |

## 8. 交叉事件

本档案负责：**住房 × 大厂**。

### 8.1 住房 × 大厂

| 种子 | 层次 | 概要 | 条件 |
| --- | --- | --- | --- |
| 公司附近 | 并行 | 你租在公司附近，通勤 15 分钟，房租占工资一半 | 大厂，一线城市 |
| 用股票付首付 | 串行 | 你把归属的股票卖了，凑够了首付 | 大厂，买房 |
| 高位上车 | 回响 | 你在{last_job.entity}最风光的那年买了房，后来房价和股价一起跌了 | 大厂，买房，下行剧本 |
| 被裁后的房贷 | 连锁 | 赔偿金能撑 8 个月房贷，你开始倒计时 | 大厂被优化，有房贷 |
| 卖房 | 抉择 | 撑不下去了：卖房 / 降价出租 / 继续撑 | 被裁后断供边缘 |

## 10. 游戏参数草案

见第 5 节。首付比例：【数据】2024-09-29 起商业性个人住房贷款不再区分首套、二套，最低首付比例统一为不低于 15%（城市可以在此基础上自行确定）。【设计】游戏里一线城市按 20%，其他城市按 15%。

## 11. 写作注意

- 不写真实楼盘、真实开发商；房价走势由时代剧本决定。
- 断供要写清楚后果和可以求助的途径（与银行协商等），不写成绝境。
