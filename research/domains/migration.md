# 领域档案：城市与迁移

| 项 | 内容 |
| --- | --- |
| 领域 id | `migration` |
| 事件量目标 | 50 条（本档案提供 18 个种子） |
| 状态 | v1，2026-10-29 |

## 1. 定义与边界

在哪个城市生活：留在一线（北漂、沪漂、深漂）、去新一线、回老家、海外院校毕业后回国落地、落户、换城市。

**状态**：`city`（城市档 + 具体城市名可选）、`hukou`（户籍）。工作地点只在中国，见设计文档。

## 2. 规模与画像

- 【报道】2025 届毕业生中 63% 流向地级及以下城市，2021 年为 58%（麦可思，经 SCMP）。
- 【数据】第七次全国人口普查：全国流动人口约 3.76 亿人（2020）【待补链接：国家统计局第七次人口普查公报】。
- 【待核实】主要城市落户政策（学历落户、社保年限、留学生落户）。

**对游戏的影响**：大城市"留下还是离开"是 25–32 岁最常见的大抉择之一；回老家不是失败，是一个有自己乐趣和代价的选择。

## 3. 触发方式

| 事件 | 【设计】触发 |
| --- | --- |
| 留下还是离开 | 在一线城市 3 年以上、无房，每两年一次 |
| 落户 | 符合条件时出现（学历、社保、留学生） |
| 回老家 | 父母生病、失业、上岸老家岗位、结婚 |
| 换城市 | 换工作、伴侣在异地 |

## 4. 22–35 岁的典型节奏

| 年龄 | 典型事件 |
| --- | --- |
| 22–25 | 去大城市闯；海归落地选城市 |
| 26–30 | 落户、留下还是离开 |
| 30–35 | 回老家、在新一线安家、为孩子上学考虑户口 |

## 5. 对状态的影响

- 城市档决定收入、房租、房价、通勤（见 data/city_tier.csv）。
- 离父母远：父母事件中"赶回家"的成本高；离父母近：催婚事件概率高。
- 回老家：收入 ×0.5–0.7，房价压力下降，心情的影响因人而异【设计：按性格随机 ±5】。

## 8. 交叉事件

本档案负责：**城市与迁移 × 体制内**。

### 8.1 城市与迁移 × 体制内

| 种子 | 层次 | 概要 | 条件 |
| --- | --- | --- | --- |
| 回去考 | 抉择 | 父母说老家在招事业编：回去考 / 留在这里 | 一线，30 岁以上 |
| 上岸回家 | 串行 | 你考上了老家的岗位，从一线城市搬了回去 | 上岸，岗位在家乡 |
| 落差 | 并行 | 第一个月工资是以前的三分之一，但你每天都能回家吃饭 | 从一线回老家体制内 |
| 被认出来 | 日常 | 在单位遇到了高中同学的妈妈，第二天全小区都知道你回来了 | 回老家体制内 |
| 偶尔想起 | 回响 | 你偶尔会想起在大城市挤地铁的日子，说不上怀念还是庆幸 | 回老家 3 年以上 |
