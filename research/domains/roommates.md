# 领域档案：室友与朋友

| 项 | 内容 |
| --- | --- |
| 领域 id | `roommates` |
| 事件量目标 | 80 条 + 200 条室友近况模板（本档案提供 34 个种子和模板结构） |
| 状态 | v1，2026-10-29 |

## 1. 定义与边界

3 个大学室友（游戏的对照组）和之后结识的朋友：宿舍群、聚会、借钱、伴郎伴娘、合伙、疏远、和解。

**数据结构**：每个室友有姓名、绰号（老大到老四 + 外号）、家乡、家境、性格、路径（由同一套引擎模拟）、和你的亲疏值（0–100）。

## 2. 规模与画像

本领域没有对应的统计数据，全部为【设计】。设计目标：

- 室友是情绪核心，见设计文档"对照组"。
- 3 个室友的毕业去向各不相同，保证对照明显。
- 亲疏值会自然衰减，需要玩家主动维护。

## 3. 触发方式

| 事件 | 【设计】触发 |
| --- | --- |
| 室友近况 | 每年年终结算时，每个室友一行 |
| 宿舍群动态 | 每年 2–4 条，活跃度随年数下降 |
| 互动事件 | 按亲疏值，亲疏 ≥ 50 时每年 1–2 条 |
| 大事 | 室友结婚、生子、失业、出事、去世时必出 |

## 4. 22–35 岁的典型节奏

| 年龄 | 宿舍群状态 |
| --- | --- |
| 22–24 | 天天有人说话，互相晒工作 |
| 25–28 | 每周几条，开始有人结婚 |
| 29–32 | 节日红包为主，偶尔有人求助 |
| 33–35 | 群里最后一条消息可能是半年前 |

## 5. 对状态的影响

- 亲疏值：每年自然 −5；互动 +5 到 +15；借钱不还 −30。
- 亲疏 ≥ 70 时：诱惑概率 ×0.5（见 crime.md），求职可获内推，心情低时有人打电话来。
- 室友的成功和挫折会影响你的心情（比较），【设计】±3。

## 6. 与路径和模块的关系

所有路径都会通过"室友近况"出现在你的事件流里，见 8.1。

## 8. 交叉事件

本档案负责：**室友近况模板（按路径）**。

### 8.1 室友近况模板（按路径）

每个室友每年一行近况，由路径和阶段决定。每条路径至少 3 个阶段 × 3–5 种说法，共约 200 条模板。示例：

| 路径 | 阶段 | 近况模板示例 |
| --- | --- | --- |
| 大厂 | 入职 | {name}进了{entity}，工牌照片发在了群里 |
| 大厂 | 被优化 | {name}说{ta}"毕业"了，配了一个笑哭的表情 |
| 白领 | 稳定 | {name}升了主管，请大家吃饭但没人有空 |
| 体制内 | 上岸 | {name}上岸了，在老家的区政府上班 |
| 备考体制 | 二战 | {name}还在考，朋友圈只剩每天的打卡 |
| 深造 | 读博 | {name}还在读博，说今年一定能毕业 |
| 服务业 | 骑手 | {name}在送外卖，说"至少自由" |
| 制造业 | 技术员 | {name}在新能源厂当工程师，三班倒 |
| 创业 | 开店 | {name}开了家奶茶店，群里所有人都去打过卡 |
| 创业 | 关店 | {name}的店关了，{ta}说"交学费了" |
| 自由职业 | 稳定 | {name}在大理接活，朋友圈全是苍山洱海 |
| 内容创作 | 爆款 | {name}的视频火了，你在推荐页刷到了他 |
| 未就业 | 待业 | {name}还在找工作，群里没怎么说话 |
| 躺平 | 全职儿女 | {name}回老家了，说在照顾{ta}爸 |
| 灰色地带 | 微商 | {name}在朋友圈卖面膜，你点了个赞没下单 |
| 违法 | 案发 | 群里没人提{name}，但大家都知道了 |
| 特殊路径 | 西部计划 | {name}去了西部，发来一张星空照片 |

模板要求：只写一行；用室友绰号或姓名；语气中性；不透露超出"室友会知道的"信息。

## 11. 写作注意

- 室友是对照，不是工具人：他们的人生也要有温度，不只是"比你好"或"比你差"。
