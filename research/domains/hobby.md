# 领域档案：兴趣与日常

| 项 | 内容 |
| --- | --- |
| 领域 id | `hobby` |
| 事件量目标 | 60 条（本档案提供 20 个种子） |
| 状态 | v1，2026-10-29 |

## 1. 定义与边界

工作之外的生活：运动、旅行、宠物、游戏、追星、阅读、做饭、手工、音乐、citywalk。这是温情事件的主要来源，保证事件流里温情和中性事件不低于 40%（见设计文档风险一节）。

**状态**：`hobbies`（最多 3 个兴趣，每个有熟练度）；模块 `pet`（宠物）。

## 2. 规模与画像

本领域暂无已核实的外部数据，以【设计】为主。

- 【待核实】养宠家庭比例、游戏用户规模、国内旅游人次。

## 3. 触发方式

| 事件 | 【设计】触发 |
| --- | --- |
| 兴趣日常 | 每年 2–4 条，按已有兴趣 |
| 新兴趣 | 每年 30%，"生活"或"兴趣"重心 ×2 |
| 养宠 | 独居或同居，每年 10% |
| 旅行 | 年假、gap、自由职业 |

## 4. 22–35 岁的典型节奏

| 年龄 | 典型事件 |
| --- | --- |
| 22–25 | 打游戏、追剧、和朋友出去玩 |
| 26–30 | 养猫养狗、健身、旅行 |
| 30–35 | 兴趣变少或变深；带孩子后兴趣时间被压缩 |

## 5. 对状态的影响

- 每个兴趣每年心情 +2，最多 +6。
- 熟练度累积到一定程度，可解锁副业或内容创作（见 8.1）。
- 宠物：心情 +3/年，花费按种类；宠物离世心情 −15。

## 6. 与路径和模块的关系

| 路径或模块 | 关系 |
| --- | --- |

## 8. 交叉事件

本档案负责：**兴趣与日常 × 内容创作**。

### 8.1 兴趣与日常 × 内容创作

| 种子 | 层次 | 概要 | 条件 |
| --- | --- | --- | --- |
| 随手发 | 并行 | 你随手发了一条做饭视频，有 300 个人点了赞 | 兴趣熟练度高 |
| 要不要认真做 | 抉择 | 有人留言说"多发点"：认真做 / 随便发发 | 随手发后 |
| 兴趣变工作 | 串行 | 爱好成了工作，你发现自己不再喜欢它了 | 转为全职创作，50% |
| 保持喜欢 | 回响 | 你没有把它变成工作，它一直是你下班后最开心的事 | 拒绝过全职 |
