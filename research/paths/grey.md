## 0. 写作底线

同 [crime.md 第 0 节](crime.md#0-本档案的写作底线)：只写处境、代价和后果，不写可操作的方法、话术、平台名和工具名。

## 1. 定义与边界

处在合法和违法之间、或者行政违法但通常不构成犯罪的营生。本路径与 `crime` 的区别：`grey` 的主要风险是罚款、封号、维权难、被骗；一旦越过刑事边界就转入 `crime`（见 8.1）。

| 类型 | 说明 | 主要风险 |
| --- | --- | --- |
| 代购 | 海外或跨地区代购，未按规定登记 | 被平台处罚、海关查扣。【数据】《电子商务法》第十条：电子商务经营者应当依法办理市场主体登记，个人零星小额交易等除外；法律没有界定"零星小额"，经常性代购通常需要登记 |
| 刷单、刷评 | 帮商家做虚假交易或好评 | 行政违法；参与者多数是受骗者，见下 |
| 代写 | 代写论文、作业、文案 | 学术不端、平台封号 |
| 微商与保健品 | 朋友圈卖货、层级分销 | 产品问题、虚假宣传；层级拉人会越线成传销 |
| 擦边内容 | 打擦边球的内容和直播 | 封号、违法风险 |
| 网贷中介、催收 | 帮人办贷款、做催收 | 越线风险高 |
| 黄牛 | 倒卖票、号、名额 | 治安处罚 |

## 2. 规模与画像

- 【数据】新修订的《反不正当竞争法》2025-10-15 起施行：第九条新增"虚假评价"，不得通过虚假评价帮助他人虚假宣传；第十三条规制利用平台规则实施虚假交易、虚假评价、恶意退货。2024 年 9 月起施行的《网络反不正当竞争暂行规定》也把"好评返现""刷单炒信"列为违法。
- 【数据】新法第二十五条：违反第九条，包括通过组织虚假交易、虚假评价等方式帮助其他经营者虚假宣传的，处 100 万元以下罚款；情节严重的，处 100 万元以上 200 万元以下罚款，可以并处吊销营业执照。处罚对象是经营者；被招募来刷单的个人主要面临平台违约追责和被骗风险。
- 【数据】公安部：刷单返利类诈骗是发案量最大、造成损失最多的电诈类型，受骗人群多为在校学生、低收入群体和无业人员（2024-06 发布的 2023 年数据）。
- 【报道】淘宝诉"刷手"案中，法院认定 24 笔交易为刷单，构成违约，对刷单参与者以民事追责为主。

**画像**：多数人进入灰色地带是因为缺钱、门槛低、"来钱快"；其中大量人实际上是受害者（例如"刷单兼职"多数是诈骗）。

## 3. 进入方式

诱惑抉择，规则同 crime.md 第 3 节：选项上写明风险，压力状态放大概率。

| 诱惑 | 【设计】出现条件 |
| --- | --- |
| 兼职刷单 | 学生、无业，每年 6%；**多数情况是诈骗**，选了之后 70% 转为"被骗钱"事件 |
| 朋友圈代购 | 有海外经历或去过境外，每年 4% |
| 代写 | 研究生、文科生，每年 3% |
| 微商 | 熟人拉入，每年 5% |
| 擦边内容 | 内容创作者，见 creator.md 8.1 |
| 网贷中介 | 无业或销售背景，每年 2% |

## 4. 轨迹

| 阶段 | 特点 |
| --- | --- |
| 尝试 | 小额收入，心里打鼓 |
| 持续 | 收入看起来不错，风险累积 |
| 出事 | 封号、被罚、被骗、或越线进入 `crime` |
| 收手 | 转正规经营（`founder`）或回去上班 |

【设计】每年出事概率 15–30%，按类型不同；每持续一年，越线概率 +5%。

## 5. 生活强度

- **心理**：一直心里不踏实，"这样做到底行不行"。
- **关系**：微商最伤熟人关系；家人不知道你在做什么。
- **钱**：收入不稳定，常常被拖欠或卷款。

## 6. 转入与转出

| 方向 | 去 / 来 |
| --- | --- |
| 转入 | 无业、学生、内容创作、服务业 |
| 转出 | 违法（越线，见 8.1）、创业（转正规经营）、回去上班、无业（被骗或封号后） |

### 8.1 灰色地带 × 违法

越线是本路径最重要的转折。越线后按 crime.md 的后果流程处理。

| 灰色 | 越线后可能构成 | 越线条件（【设计】） |
| --- | --- | --- |
| 微商拉人头 | 组织、领导传销活动罪。【数据】组织内参与传销活动人员 30 人以上且层级 3 级以上的，追究组织者、领导者刑事责任（2013 年两高一部意见）；一般参与者主要面临行政处罚和财产损失 | 成为组织者、领导者：发展下线并按人头计酬 |
| 刷单、跑分 | 帮信罪 | 提供账户帮助资金流转 |
| 网贷中介、催收 | 催收非法债务罪。【数据】刑法第二百九十三条之一（2021-03-01 起）：以暴力、胁迫，限制人身自由或侵入住宅，恐吓、跟踪、骚扰等方式催收高利放贷等非法债务，情节严重的，处三年以下有期徒刑、拘役或管制 | 用暴力或软暴力方式催收 |
| 代购 | 走私普通货物、物品罪。【数据】偷逃应缴税额 10 万元以上为"较大"，50 万元以上为"巨大"（2014 年两高走私案件司法解释第十六条）；【报道】曾有代购店主偷逃税额 300 余万元，被判 10 年 | 逃避海关监管，偷逃税额达到门槛 |

| 种子 | 方向 | 层次 | 概要 | 条件 |
| --- | --- | --- | --- | --- |
| 边界 | 灰色 → 违法 | 抉择 | 上线让你"帮忙收一下款，走你的账户"：拒绝 / 答应 | 微商或刷单持续 1 年以上 |
| 越线了 | 灰色 → 违法 | 串行 | 你后来才知道，那一步已经不是"灰色"了 | 越线案发 |
| 律师的话 | 灰色 → 违法 | 日常 | 律师说"你以为是兼职，法律上不这么看" | 案发后 |
| 及时收手 | 灰色 | 回响 | 你在越线前一个月收了手，后来那个群里的人都被带走了 | 选了收手，同伴案发 |

**履历短句**：做过{n}年代购 / 微商，后来{next_path}
