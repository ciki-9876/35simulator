## 1. 定义与边界

工厂和技术工种：电子厂、汽车与新能源产线、制造业技术员、电工、焊工、汽修、设备维护、质检，以及建筑工地的技术工。

**子状态**：

| 子状态 | 说明 |
| --- | --- |
| 普工 | 流水线，倒班，按小时或计件 |
| 技术工 | 有证书的电工、焊工、数控等 |
| 技术员 / 班组长 | 本路径内的晋升 |
| 派遣工 | 通过劳务派遣进厂，稳定性最低 |

## 2. 人群规模与画像

- 【数据】2025 年全国农民工总量 30,115 万人，比上年增加 142 万；月均收入 5,075 元（外出农民工 5,774 元，本地农民工 4,376 元；东部 5,501 元）。
- 【数据】2025 年农民工平均年龄 43.3 岁，比上年提高 0.1 岁；外出农民工平均年龄 39.3 岁；40 岁及以下占 44.2%，50 岁以上占 32.0%。
- 【数据】2025 届本科毕业生进入电子电气设备制造业 7.0%、机械设备制造业 4.2%、交通运输设备制造业 2.3%，均比 2021 届上升；"绿牌专业"包括电气工程及其自动化、微电子、自动化、车辆工程、新能源科学与工程。

**画像**：两类年轻人。一类是专科或高中学历、从农村出来的进厂青年；另一类是本科工科生进入新能源、半导体工厂当技术员或工程师。后者是近年增长最快的方向。

## 3. 进入方式

| 渠道 | 说明 |
| --- | --- |
| 劳务中介 | 门槛最低，有中介费和"返费"陷阱 |
| 工厂直招 | 校园招聘或工厂门口招工 |
| 技校、专科 | 带证书入行 |
| 本科工科 | 以技术员、工艺工程师身份进入 |

## 4. 轨迹

| 阶段 | 收入（【设计】待校准，月收入） | 说明 |
| --- | --- | --- |
| 普工 | 4–6k，旺季加班到 7k | 倒班，加班费是主要增量 |
| 技术工 | 6–9k | 考证后 |
| 班组长 / 技术员 | 7–12k | — |
| 工程师（本科入口） | 8–15k | 新能源、半导体 |

- 【设计】普工每年流动率高，平均 1–2 年换一次厂；考证让收入 +20–30%。
- 制造业受时代剧本影响大：订单多时加班多、收入高；订单少时放假、减薪。

## 5. 生活强度

- **时间**：两班倒、12 小时班、旺季连续上班。
- **身体**：噪音、粉尘、站立、职业病风险（见 [body.md](../domains/body.md) 8.1）；工伤。
- **生活**：住厂区宿舍，生活圈小；恋爱多在厂内或老乡圈。
- **钱**：花销小、存钱快；但没有长期上升通道的焦虑。

## 6. 转入与转出

| 方向 | 去 / 来 |
| --- | --- |
| 转入 | 应届（专科、工科本科）、无业、服务业（见 8.1） |
| 转出 | 服务业（见 8.1）、创业（开汽修店、小作坊）、回老家、技术工 → 白领（工程师转管理） |

### 8.1 制造业 × 服务业一线

"进厂还是送外卖"是这代年轻人最真实的二选一之一。

| 方向 | 场景 | 【设计】频率 |
| --- | --- | --- |
| 制造业 → 服务业 | 嫌工厂管得严、时间不自由，转去送外卖 | 普工中每年 10% |
| 服务业 → 制造业 | 骑手太累、收入不稳，进厂图个稳定 | 骑手中每年 5% |

| 种子 | 方向 | 层次 | 概要 | 条件 |
| --- | --- | --- | --- | --- |
| 二选一 | 抉择 | 抉择 | 进厂 / 送外卖：一边管吃住，一边时间自由 | 无业，学历 ≤ 专科，或本科失业 ≥ 6 个月 |
| 不想被管 | 制造业 → 服务业 | 串行 | 你辞了厂里的工作，买了一辆二手电动车 | — |
| 不用打卡 | 制造业 → 服务业 | 日常 | 第一次不用打卡，你睡到了十点 | 刚转出 |
| 回厂里 | 服务业 → 制造业 | 串行 | 跑了一年外卖，你回到了厂里，至少下雨天不用在外面 | — |
| 两种累 | 回响 | 回响 | 你说厂里累的是心，外卖累的是腿 | 两段经历都有 |

**履历短句**：进过厂，也送过外卖，后来{next_path}
