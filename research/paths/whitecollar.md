## 1. 定义与边界

在大厂以外的企业里做办公室工作：外企、民企、国企职能岗，以及金融、咨询、地产、快消、制造业总部、中小互联网公司。岗位包括职能（人事、财务、法务、行政）、销售与商务、市场、项目管理、中小公司的技术岗。

**子状态**：

| 子状态 | 说明 |
| --- | --- |
| 管培生 | 应届入职的轮岗培养项目，常见于快消、地产、制造业 |
| 普通职员 | 主体 |
| 主管 / 经理 | 带人，承担业绩 |
| 驻外 / 常出差 | 销售、咨询、工程项目常见 |

**不包含**：头部互联网大厂归 `bigtech`；公务员、事业单位归 `public`。国企按"编制外的企业员工"处理，归本路径，但稳定性系数高一档。

## 2. 人群规模与画像

- 【数据】2025 届本科毕业生就业行业中，金融业占 6.6%，电子电气设备制造业 7.0%，机械设备制造业 4.2%（麦可思）。
- 【数据】2025 年城镇单位平均工资：非私营单位 129,441 元，私营单位 71,590 元；金融业非私营单位 211,164 元，私营单位 140,451 元。
- 【数据】2025 年全国企业就业人员周平均工作时间 48.6 小时，2023、2024 年均为 49 小时，是连涨 9 年后的首次回落；超过法定标准工时（每周 40 小时）。

**画像**：人数最多的一条"上班"路径。收入差距很大：一线城市的金融、咨询岗和县城的民企文员都在这条路径里，城市档和行业系数决定一切。

## 3. 进入方式与门槛

| 渠道 | 说明 |
| --- | --- |
| 秋招 / 春招 | 学历筛选弱于大厂，【设计】院校档系数 985 为 1.0、普通本科 0.6、专科 0.3 |

## 4. 22–35 岁轨迹

| 游戏职级 | 典型年龄 | 一线城市年薪（【设计】待校准） | 县城 / 三四线 |
| --- | --- | --- | --- |
| 职员 | 22–26 | 10–20 万 | 4–8 万 |
| 资深职员 | 25–30 | 15–30 万 | 6–10 万 |
| 主管 | 28–33 | 25–45 万 | 8–15 万 |
| 经理 | 31 以上 | 40–80 万 | 12–25 万 |

- 金融、咨询类岗位按 ×1.5，快消、制造业职能按 ×0.9（【设计】）。
- 晋升比大厂慢，但被优化的概率也低。【设计】每年被裁 2%，私营小公司 4%，国企 0.5%。
- 跳槽是涨薪主力：【设计】每次 10–25%。

## 5. 生活强度

- **时间**：周均工时接近 49 小时是全国企业平均；销售、咨询、投行远高于平均，国企职能岗低于平均。
- **出差**：销售、咨询每年出差 60–150 天，【设计】心情 −2、关系 −3、存款 +（补贴）。
- **人际**：办公室政治、站队、"向上管理"。
- **钱**：一线城市收入能覆盖租房，但买房普遍要靠家里支援。

## 6. 转入与转出

| 方向 | 去 / 来 | 触发 |
| --- | --- | --- |
| 转出 | 大厂 | 跳槽，见 8.1 |
| 转出 | 备考体制 | 想要稳定、回老家 |
| 转出 | 创业 / 自由职业 | 带着客户或技能出来单干 |
| 转出 | 未就业 | 被裁、公司倒闭、裸辞 |
| 转出 | 违法 | 有采购、审批权限后的诱惑（规则同 crime.md 8.1） |
| 转入 | 无业、深造、大厂 | 求职成功、毕业、从大厂降级求稳 |

## 8. 与其他路径的交叉事件

写法和通用变量见 [bigtech.md 第 8 节](bigtech.md#8-与其他路径的交叉事件)。

本档案负责：**白领 × 大厂**。相关的对：白领 × 违法的权限诱惑沿用 [crime.md 8.1](crime.md#81-违法--大厂) 的规则，把"大厂"换成白领即可。

### 8.1 白领 × 大厂

| 方向 | 场景 | 【设计】频率 |
| --- | --- | --- |
| 白领 → 大厂 | 跳槽进大厂，涨薪但加班更重 | 白领中约 6% |
| 大厂 → 白领 | 被优化后降级求稳、去国企或银行科技岗 | 离开大厂的人约 35% |
| 回响 | 两种工作文化的对比 | 每局 1–2 条 |

**机制修正**（【设计】）：从大厂到白领，薪资 ×0.6–0.8，加班强度 −1 档，被裁概率 ×0.5；从白领到大厂，要求能力 ≥ 60，薪资 ×1.3–1.6。
