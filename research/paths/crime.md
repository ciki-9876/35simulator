## 0. 本档案的写作底线

这条路径写的是**处境、代价和后果**，不是"犯罪职业"。

- 不写任何可操作的方法：不写怎么转账、怎么规避风控、话术、平台名、工具名。事件只写"你做了什么事"的一句概括和随后发生的事。
- 玩家不会在菜单里"选择当罪犯"。违法只会以**诱惑抉择**的形式出现：在缺钱、失业、朋友拉拢这些压力下，选项上明确写出风险。
- 后果真实且有分量：冻卡、传唤、拘留、判刑、前科，对本人和家人的长期影响。
- 同一主题同时写受害者视角，比如被骗出境、被骗钱，这些放在"钱"领域和本路径的交叉事件里。
- 数据锚点只用官方统计和公开报道。

## 1. 定义与边界

22–35 岁人群中比较常见的违法犯罪，以及之后的司法流程和人生后果。

**覆盖的类型**：按与年轻人的相关度排序。

| 类型 | 说明 | 常见入口 |
| --- | --- | --- |
| 帮信 | 帮助信息网络犯罪活动罪：把银行卡、电话卡、账号借给或卖给别人，为诈骗等犯罪提供帮助 | 缺钱、兼职广告、熟人介绍 |
| 危险驾驶（醉驾） | 起诉人数最多的罪名之一 | 应酬、聚会后开车 |
| 被骗出境与电诈 | 被"高薪招聘"骗到境外，被迫参与诈骗，回国后可能被追诉 | 失业、求职 |
| 网络赌博 | 参赌属于治安违法；当代理、组织他人参赌可能构成犯罪 | 体育赌博、朋友拉 |
| 传销 | 被骗进入，或拉人后变成参与者 | 熟人介绍"项目" |
| 职务侵占 / 受贿 | 白领或大厂员工收供应商好处、挪用公司财物 | 有权限以后 |
| 侵犯公民个人信息 | 出售或泄露工作中接触到的用户数据 | 技术或数据岗位 |
| 吸毒 | 治安违法，强制戒毒 | 圈子、娱乐场所 |

**子状态**：

| 子状态 | 说明 |
| --- | --- |
| 隐患期 | 做了，还没被发现。事件流里有"不安"的提示 |
| 案发 | 冻卡、被传唤、被拘留 |
| 取保 / 审理 | 等待判决，生活和工作受影响 |
| 服刑 | 时间跳过，只给几条狱中和家人的事件 |
| 缓刑 / 行政处罚后 | 回到社会但受限制 |
| 刑满释放 | 带着前科重新开始，通常转入"未就业" |

## 2. 规模与画像

- 【数据】起诉"非法买卖电话卡和银行卡、帮助提款转账等犯罪"（即帮信等）的人数，从 2018 年的 137 人增至 2022 年的 13 万人，帮信罪成为起诉人数第三多的罪名，仅次于危险驾驶罪和盗窃罪（最高检工作报告）。
- 【数据】2022 年帮信犯罪嫌疑人中，初中以下学历占 66.3%，无固定职业的占 52.4%；本科以上学历、民企员工（尤其是收入较高的科技公司员工）涉罪人数持续增加。
- 【数据】中国司法大数据显示，过去五年近七成帮信罪人员是 30 岁以下的年轻人；涉案人员低龄化、低学历、低收入，初犯比例高。上游犯罪者会引诱在校学生、刚毕业的大学生和收入不稳定的年轻人参与（最高法副院长李勇，2024-03）。
- 【数据】2023 年全国法院一审审结电诈犯罪案件 3.1 万余件，判处被告人 6.4 万余名，分别比上年上升 48.36% 和 38.64%。
- 【数据】最高检 2026-03-10 发布 2025 年"四大检察"白皮书：全年提起公诉 140.4 万人，同比下降 13.9%；批准和决定逮捕 66.4 万人，同比下降 11.7%。
- 【报道】同一白皮书称帮信犯罪同比下降 61.7%，但报道没有说明是受理、批捕还是起诉的口径，不要写成"起诉下降 61.7%"。
- 【报道】2025 年起诉利用网络实施的犯罪 18.2 万人、电信网络诈骗犯罪 6.9 万人（经 IT 之家转述）【待核实原文】。
- 【数据】2026 年 1–6 月，全国检察机关起诉利用网络实施的犯罪 7.7 万人、电信网络诈骗犯罪 3.2 万人；同期提起公诉 60.3 万人，同比下降 11.5%（最高检，2026-07-16）。
- 【数据】公安部提示：境外诈骗集团常用"高薪工作、包吃包住、报销机票、专人接送"引诱境内人员出境，出境后强迫其从事电诈（2025-01）。
- 【报道】从缅甸妙瓦底地区遣返的中国籍涉诈嫌疑人累计超过 7,600 人【待核实发布日期】。

**画像**：帮信和被骗出境集中在 30 岁以下、收入不稳定、刚毕业或失业的人；醉驾和职务侵占集中在有车、有一定职位的 25–35 岁人群。

## 3. 进入方式（诱惑抉择）

每个诱惑抉择都要在选项上写明风险，并且受压力状态影响出现概率。

| 诱惑 | 出现条件（【设计】） | 选项与风险提示 |
| --- | --- | --- |
| 出借银行卡 | 存款低或失业；每年 3%，学生和应届生 ×1.5 | "借出去，每月有一笔钱 · 可能涉嫌违法" / 拒绝 |
| "高薪"境外工作 | 失业 3 个月以上且存款低；每年 2% | "去 · 对方信息无法核实" / 拒绝 / 报警核实 |
| 酒后开车 | 有车，参加聚会或应酬；每年 5% | 叫代驾 / 自己开回去 · "只喝了一点" |
| 体育赌博 | 每年 4%，男性 ×1.5 | 试一次 / 不碰 |
| 朋友的"项目" | 每年 3%，熟人介绍 | "加入 · 要先交钱拉人" / 拒绝 |
| 供应商的红包 | 有采购、审批等权限；每年 6% | 收下 / 退回 / 上报 |
| 卖数据 | 技术或数据岗；每年 1% | "帮忙导一份 · 有人给钱" / 拒绝 |
| 第一次碰毒品 | 每年 0.5%，夜场社交 | 拒绝 / 试一次 |

## 4. 后果流程

```
做了 → 隐患期（每年按"案发概率"判定）→ 案发 → 处理结果 → 长期后果
```

| 类型 | 【设计】每年案发概率 | 可能的处理结果 |
| --- | --- | --- |
| 出借银行卡 | 第一年 40%，之后每年 30% | 冻卡、拘留、帮信罪判刑（有期徒刑或拘役，可能缓刑）、罚金 |
| 被骗出境 | 必然受害；回国时 60% 被调查 | 受害者 → 被解救；或被追诉 |
| 醉驾 | 查到即案发，每次 25% | 吊销驾照、拘役、可能缓刑、可能被开除 |
| 体育赌博 | 不一定"案发"，主要后果是输钱和上瘾 | 参赌：治安处罚；当代理：可能涉罪 |
| 传销 | 每年 30% | 被骗钱、被拘、亲友关系破裂 |
| 职务侵占 / 受贿 | 每年 20% | 被开除、上内部反腐通报、判刑 |
| 卖数据 | 每年 25% | 开除、判刑、行业内"出名" |
| 吸毒 | 每年 30% | 强制隔离戒毒、复吸风险 |

**从宽与从严**：【数据】处罚原则是"依法从严惩处、全面惩处、准确惩处"，同时宽严相济：在共同犯罪中起次要作用的、被诱骗或胁迫参与的、初犯偶犯、主动投案、积极退赃的，可以从宽；越早投案越可能从轻。2025 年"两高一部"的意见规定，在校学生实施帮信犯罪的参照从宽处理。
- 【设计】游戏里体现为抉择："主动投案 / 等着"。投案让判决档位下降一档。

**长期后果**：

- 【数据】前科报告制度：受过刑事处罚的人，在入伍、就业时应如实报告。
- 【数据】《公务员法》规定，因犯罪受过刑事处罚的，不得录用为公务员（现行 2018 年修订版第二十六条；未查到 2025 年的修订）。
- 【数据】《公职人员政务处分法》第十四条：公职人员因故意犯罪被判处管制、拘役或者有期徒刑以上刑罚（含宣告缓刑）的，予以开除。
- 【报道】部分犯罪记录会在一定期限内影响担任公司董事、监事和高管。对近亲属入伍、政审的影响没有全国统一标准，各单位规定不同，游戏里只写"可能影响"。
- 【数据】新修订的《治安管理处罚法》自 2026-01-01 起施行，第 136 条规定治安违法记录应予封存，不得向任何单位和个人提供或公开，依法查询的除外。也就是说，"治安处罚"和"刑事前科"的后果差别很大，游戏要区分。
- 【报道】部分用人单位直接设置"无犯罪记录"门槛。

【设计】游戏内效果：

| 后果 | 效果 |
| --- | --- |
| 刑事前科 | 永久关闭"体制内"和"备考体制"路径；大厂、国企录用率 ×0.1；企业白领 ×0.3 |
| 治安处罚（已封存） | 对求职基本没有影响，但本人心理和家人关系受影响 |
| 服刑 | 时间跳过；存款冻结或清零；伴侣关系有概率结束；父母健康 −10 |
| 出狱 | 转入"未就业"，带"前科"标记 |

## 5. 生活强度

- **隐患期**：每年心情 −5（"每次手机响都心里一紧"）。
- **案发和审理**：工作大概率丢掉，家人知道，存款用来退赃、交罚金、请律师。
- **服刑**：时间跳过，按"季"给 3–5 条事件：家人探视、学会一门手艺、收到室友的信。
- **出狱后**：求职受限、亲友疏远或接纳、自我认同。

### 8.1 违法 × 大厂

**两条路径怎么相遇**：

| 方向 | 场景 | 【设计】频率 |
| --- | --- | --- |
| 大厂 → 违法 | 有了权限以后的诱惑（收供应商好处、卖数据）、应酬后醉驾、高收入下的赌博、接涉罪私活 | 进过大厂的人约 3% 在 35 岁前有过一次 |
| 违法 → 大厂 | 基本关闭：刑事前科让大厂录用率 ×0.1；只有治安处罚（已封存）时不受影响 | — |
| 同时存在 | 在职期间的隐患期：内部审计、反腐调查、背景调查 | — |
| 回响 | 反腐通报、同事被带走、35 岁结局 | 每局约 0–2 条 |

**和"无业 × 违法"的区别**：大厂里的违法几乎都不是因为缺钱，而是因为**有了权限和机会**。所以诱惑的出现条件看职级、岗位和收入，不看存款。

**机制修正**（【设计】）：

| 规则 | 效果 |
| --- | --- |
| 权限带来诱惑 | 供应商红包：L3 以上且负责采购、选型或商务对接，每年 6%；卖数据：能接触用户数据的岗位，每年 1% |

## 11. 写作注意

- 第 0 节的底线优先于一切。
- 受害者优先：被骗出境的事件以受害者处境为主，回国后的追诉作为一种可能，不作为"活该"。
- 不美化：不写"一夜暴富"的爽感；钱的收益要小，风险和后果要大，且要写清楚。
- 前科后果写清楚，但给出"重新开始"的可能，避免宿命论。
- 每个案发事件后附一句法律常识，例如"出借银行卡可能构成帮信罪"，以及反诈求助渠道。
- 内容审核：这条路径的所有事件上线前要单独过一遍法律审核。
