# 路径档案：自由职业与零工

| 项 | 内容 |
| --- | --- |
| 路径 id | `freelance` |
| 事件量目标 | 140 条（本档案提供 25 个种子） |
| 状态 | v1，2026-10-29 |

## 1. 定义与边界

不受雇于单一单位、靠技能接单：设计、插画、翻译、外包程序员、摄影摄像、剪辑、私教、家教、陪诊、陪玩、数字游民。

**和其他路径的边界**：

| 情况 | 归属 |
| --- | --- |
| 靠平台派单的跑腿、骑手、网约车 | `service` |
| 靠流量和粉丝变现的博主、主播 | `creator` |
| 在职期间接私活 | 原路径 + `side_job` 模块 |

## 2. 人群规模与画像

- 【数据】2025 届本科毕业生自由职业 3.0%，高职 4.4%（麦可思）；灵活就业合计本科 6.9%、高职 10.9%，比 2021 届分别上升 2.7 和 3.2 个百分点。
- 【数据】灵活就业人员规模超过 2 亿（人社部测算）。

**画像**：两种人。一种是有一技之长、主动选择自由的人，多在大厂或公司干过几年；另一种是找不到稳定工作、先接零活的人。

## 3. 进入方式

| 来源 | 【设计】条件 |
| --- | --- |
| 从大厂或白领出来 | 能力 ≥ 60，有人脉，见 8.1 |
| 应届直接自由职业 | 有作品集的艺术、设计类专业 |
| 失业后接零活 | 失业 ≥ 3 个月 |
| 副业转正 | 副业收入连续 6 个月超过主业的一半 |

## 4. 轨迹

| 阶段 | 特点 | 【设计】月收入 |
| --- | --- | --- |
| 起步 | 靠熟人介绍，价格低 | 2–8k，波动大 |
| 稳定 | 有回头客和口碑 | 8–20k |
| 天花板 | 时间换钱的上限；开工作室（转 `founder`）或回去上班 | 15–30k |

- 收入按月抽取，有空窗月。【设计】每年有 2–4 个月收入低于平时的一半。
- 社保、医保自己交；没有公积金，影响贷款买房。

## 5. 生活强度

- **时间**：自由但没有边界，赶稿时通宵。
- **钱**：现金流焦虑，追尾款。
- **心理**：自由感 vs 孤独感、不被家人理解（"什么时候找个正经工作"）。
- **关系**：在家办公，社交圈变小。

## 6. 转入与转出

| 方向 | 去 / 来 |
| --- | --- |
| 转入 | 大厂、白领、无业、服务业 |
| 转出 | 回去上班、开工作室（`founder`）、做内容（`creator`）、无业 |

| 追债 | 抉择 | 发律师函 / 继续催 / 算了 | 尾款拖欠 ≥ 3 个月 |
| 空窗月 | 日常 | 这个月一单都没有，你把存款看了三遍 | 见第 4 节 |
| 社保自己交 | 抉择 | 每月交 1,000 多的社保：交 / 先不交 | 每年 |
| 在家办公 | 日常 | 连续五天没出门，外卖小哥是你见到的唯一一个人 | — |
| 咖啡馆 | 日常 | 你去咖啡馆办公，一杯美式坐了六个小时 | — |
| 数字游民 | 抉择 | 去大理 / 去海边小城住几个月：去 / 不去 | 能远程，收入稳定 |
| 家人不理解 | 日常 | 母亲说"你这算失业吧" | 和父母同城或春节 |
| 贷款被拒 | 连锁 | 买房贷款时银行要收入证明，你拿不出来 | 想买房 |
| 回头客 | 日常 | 一个老客户又找你了，还介绍了他的朋友 | 稳定期 |
| 平台抽成 | 日常 | 接单平台抽了 20%，你算了一下，时薪不如上班 | 用平台接单 |

| 学 AI | 抉择 | 用 AI 提效接更多单 / 坚持手工 | AI 剧本 |
| 生病没人顶 | 连锁 | 发烧三天，两个项目全部延期 | 健康 < 50 |
| 开工作室 | 抉择 | 单子多到接不完：招人开工作室 / 维持一个人 | 稳定期，订单饱和 |
| 回去上班 | 抉择 | 一个公司想全职招你：去 / 继续自由 | 每年 15% |

## 8. 与其他路径的交叉事件

写法和通用变量见 [bigtech.md 第 8 节](bigtech.md#8-与其他路径的交叉事件)。

本档案负责：**自由职业 × 大厂**。相关：内容创作 × 无业见 [creator.md 8.2](creator.md#82-内容创作--无业)。

### 8.1 自由职业 × 大厂

| 种子 | 方向 | 层次 | 概要 | 条件 |
| --- | --- | --- | --- | --- |
| 接私活 | 大厂（并行） | 抉择 | 以前的同事介绍了一个外包项目：周末接 / 不接 | 在大厂，`side_job` 模块；注意竞业和公司规定 |
| 私活被发现 | 大厂（并行） | 连锁 | HR 约谈你，说私活违反了员工手册 | 接私活，每年 10% |
| 裸辞自由 | 大厂 → 自由职业 | 抉择 | 存够了一年的生活费，你想出来自己干：辞 / 不辞 | 大厂 3 年以上，存款 ≥ 一年生活费 |
| 老东家当甲方 | 大厂 → 自由职业 | 日常 | 你的第一个客户，是你原来那个组 | 从大厂出来 |
| 没有年终奖 | 大厂 → 自由职业 | 回响 | 一月份，以前的同事在群里晒年终奖，你在追一笔尾款 | 从大厂出来，`{last_job.entity}` |
| 回到大厂 | 自由职业 → 大厂 | 串行 | 自由了两年，你又戴上了工牌 | 能力 ≥ 60 |

**履历短句**：从{last_job.entity}出来，自由了{n}年
